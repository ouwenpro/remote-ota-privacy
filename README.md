# remote OTA privacy policy

Public English and Simplified Chinese privacy policy for remote OTA on Android and iOS.

Published URL: https://ouwenpro.github.io/remote-ota-privacy/

GitHub Pages source: `main`, repository root (`/`). The site is static HTML with no build step, analytics, cookies added by the page, or external assets. GitHub's hosting privacy practices apply to requests to the site.

Update `index.html` and its policy date when the app's data practices change. This repository contains only public policy content; do not add app source, firmware, signing keys or credentials.
